# Contributing

This repository follows the shared Zuma contribution and review process:

**https://github.com/guada-labs/zuma/blob/main/CONTRIBUTING.md**

In short:

- Every change starts as an issue in this repository; claim it by assigning yourself.
- Branch from `main`, open a pull request, and get one approval from someone other than the author.
- Keep pull requests small (target ≤ 400 changed lines) and describe what, why and how it was tested.
- The shared guide defines the review checklist, the Definition of Done, and the reporting standard.

Run this repository's checks before requesting review.
